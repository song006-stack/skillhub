# SkillHub 桌面版（开发预览）

该目录是独立的本地 MCP 插件，使用 OpenAI 的会话和全局应用入口。它不会更改或覆盖 Edge 扩展，也不会自动访问 Edge 的扩展存储。

用户选择文件夹后，浏览器容器将所选 Skill 文件保存到应用的 IndexedDB 中；脚本不会自动执行。记录包括原始文件的副本，但当前版本没有资源导出功能，请保留原始文件。技能名称及内容完全相同的条目合并显示。收藏、编辑和最近使用由应用本地存储管理。重复导入相同的相对路径会更新文件并保留原有资料。

点击“识别本机技能”后，本地 MCP 服务只扫描当前用户的 `.codex/skills` 和 `.agents/skills`，读取其中的 SKILL.md，不跟随符号链接、不扫描依赖目录，也不执行脚本。识别只保存技能说明和来源路径；其他资源保留在原目录，不复制或上传。删除或移动原始目录后，相关资源将不可用。非这两个目录的技能仍需手动导入。

目前 SkillHub 无法核验 ChatGPT 或 Codex 当前会话可调用的技能清单。旧版基于关键词推断的平台会显示为“待确认”；你可以点击技能名称手动标记平台。ChatGPT、Codex 筛选只包含相应手动标记及手动标记为通用的技能，不保证技能已安装、已启用或能够在当前会话执行。原有技能数据与旧标记仍保留。

点击顶部“语言”可切换中文或英文，也可以导入 JSON 语言文件。格式为 `{"code":"fr","name":"Français","strings":{"all":"Tout"}}`；`code` 不能与已有语言重复，`strings` 使用示例文件中的键，未提供的键回退到中文。导入的文件是数据，不执行代码。界面和调用语句会切换语言，技能原始名称及介绍保持不变。关闭其他 SkillHub 面板后再更新，有助于本地数据库升级。

点击“插入”向宿主请求将简短的技能调用请求加入当前对话草稿；是否支持该操作取决于宿主。简短请求不包含 SKILL.md，只有 ChatGPT 当前环境能访问相应 Skill 时才可能实际调用。

本机需要 Node.js 20 或更高版本，并能从 ChatGPT 启动进程时在 PATH 中找到 `node`。应用文件选择器、IndexedDB、插件安装和消息插入都需要在目标 ChatGPT 桌面版中实际验证。页面需要用户自行选取技能文件夹，现有 Edge 收藏和历史不能自动迁移；GitHub 导入和多 Skill 组合调用尚未移植。

开发时在项目父目录运行 `node desktop-plugin/build.cjs`，执行 `node --test desktop-plugin/test.cjs`。打包使用插件根目录的 `plugin.json`、`mcp.json`、`server.cjs`、`panel.html`；无需把 node_modules 打包进去。
