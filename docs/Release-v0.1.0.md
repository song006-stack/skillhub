# SkillHub v0.1.0

SkillHub 的首个 GitHub 发布预览，提供浏览器侧边栏和桌面 MCP 插件两种使用方式。

## 已实现

- 按名称、介绍和关键词搜索；分类浏览、收藏、最近使用及编辑技能资料。
- 从本地文件夹导入 Skill，保留文件和相关资源；重复技能合并显示。
- 桌面版手动识别本机常用 Skill 目录，支持中文、英文和自定义语言文件。
- 浏览器版可记住用户授权的技能目录，并在授权有效时重新识别；权限由浏览器管理。
- 浏览器版支持导入公开 GitHub 仓库默认分支的 Skill。
- 根据平台标记筛选，并向对话插入简短调用请求。

## 安装

- `SkillHub-v0.1.0-browser.zip`：Chrome／Edge 开发者模式下加载解压后的文件夹。
- `SkillHub-v0.1.0-desktop.zip`：桌面本地 MCP 插件及本地市场配置，安装要求 Node.js 和支持本地插件的客户端。
- 完整步骤见 [中文安装指南](https://github.com/song006-stack/skillhub/blob/main/docs/%E5%AE%89%E8%A3%85%E6%8C%87%E5%8D%97-v0.1.0.md)。

## 已知限制

- 两个版本的数据不同步；桌面版尚不支持 GitHub 导入和多 Skill 组合调用。
- 平台标记并不能证明技能在当前会话中已安装或可用；插入的简短请求不会自动上传技能说明或资源。
- 本机扫描不会自动执行技能脚本；请保留技能原始文件的备份。
- 浏览器页面结构或桌面客户端能力改变时，集成可能需要调整。桌面安装流程需在目标客户端实际验证。

本次整体发布版本为 `v0.1.0`，包内组件版本分别为浏览器扩展 `0.1.7` 和桌面插件 `0.1.10`；不会修改组件自身的清单版本。
