# SkillHub v0.1.0 安装指南

请从 [v0.1.0 发布页面](https://github.com/song006-stack/skillhub/releases/tag/v0.1.0) 下载文件。该链接在发布后生效。两个版本的数据互不共享；请按你的使用场景选择。

## 浏览器扩展（Chrome／Edge）

1. 下载 `SkillHub-v0.1.0-browser.zip`，右键选择“全部解压缩”，将文件保存在不会随意删除的位置。
2. 在 Edge 地址栏输入 `edge://extensions`，或在 Chrome 输入 `chrome://extensions`。
3. 打开“开发人员模式”，点击“加载解压缩的扩展”。
4. 选择解压后的 `SkillHub-v0.1.0-browser` 文件夹，确认文件夹中有 `manifest.json`。
5. 在同一个浏览器打开或刷新 [ChatGPT](https://chatgpt.com/)，点击工具栏扩展图标，选择 SkillHub 打开侧边栏。

这是开发者模式下的本地安装包，不是扩展商店自动更新包。请保留解压文件夹。若看不到扩展图标，请在浏览器的扩展菜单中查找并固定。

## 桌面插件（开发预览）

桌面包通过本地 MCP 运行，需要支持本地插件市场的 ChatGPT／Codex 桌面客户端和 Node.js 20 或以上版本。安装与显示入口受客户端版本、账号和本机环境影响；本包未上架 OpenAI 公共插件目录。

1. 下载 `SkillHub-v0.1.0-desktop.zip` 并解压到一个保留的位置，例如 `C:\SkillHub\desktop`。解压后的目录应包含 `.agents`、`plugins` 和 `安装说明.md`。如果文件管理器隐藏了以点开头的目录，先启用“显示隐藏的项目”。
2. 打开 PowerShell，先检查 Node.js：运行 `node --version`，应显示 v20 或更高版本。请从 [Node.js 官方网站](https://nodejs.org/)安装并重新打开终端，确保 `node` 可用。
3. 检查是否有 Codex CLI：运行 `codex --version`。如果命令不可用，请先参考 [OpenAI 的 Codex 文档](https://developers.openai.com/codex/cli)安装或配置。然后执行：

   ```powershell
   codex plugin marketplace add "C:\SkillHub\desktop"
   ```

   将路径替换为**解压后包含 `.agents` 和 `plugins` 的目录**。这会注册本地插件市场；不要删除该目录。
4. 重启 ChatGPT 桌面应用，在“插件”目录选择 `SkillHub Local`，安装 SkillHub。打开一个本地会话，选择或 @ SkillHub 并请求“打开 SkillHub”。若客户端没有显示该本地市场，请检查客户端及账号是否支持本地插件。
5. 在 SkillHub 中点击“识别本机”，扫描当前用户的 `.codex/skills` 和 `.agents/skills`，或用“导入”选择其他技能文件夹。

此安装流程依据 OpenAI 的[本地插件市场文档](https://developers.openai.com/plugins/build/plugins)整理，仍需在目标设备上验证。公共插件目录中的桌面本地 MCP 发布另有准入要求；本 GitHub 包不代表已经上架或通过 OpenAI 审核。

## 使用和隐私提示

点击技能名称可编辑介绍、分类和平台；点击星标收藏；点击“插入”把简短请求放进对话。桌面版的平台分类需要用户自行标记，“待确认”表示尚未标记；它不能验证当前会话是否实际可调用该技能。

SkillHub 不会自动执行导入脚本。识别本机技能时只读取 `SKILL.md`；相关资源保留在原目录。插入调用语句不会自动上传技能说明或其他文件，请保留原始技能文件备份。
